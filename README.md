# Telco Customer Dashboard

## Overview
A Power BI dashboard built to analyze telecom customer data, focusing on churn analysis, service usage patterns, and customer demographics.

## Tools Used
- Power BI Desktop
- DAX

## Key Insights
- Customer churn rate and drivers
- Service subscription breakdown
- Revenue by customer segment

## How to View
1. Download the `.pbix` file
2. Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
